# corrupt952

Building small tools that get out of the way — CLIs, Chrome extensions, and the
automation that keeps them running.

## CLI

- [sallyport](https://github.com/corrupt952/sallyport) — A trust-based, per-directory shell hook for zsh
- [closest](https://github.com/corrupt952/closest) — Searches the current directory or its parents for a file and returns the closest path
- [tmuxist](https://github.com/corrupt952/tmuxist) — Manage tmux sessions from a configuration file
- [xckit](https://github.com/corrupt952/xckit) — CLI tool for managing Xcode String Catalogs (`.xcstrings`)

## Chrome extensions

- [Snack Time](https://github.com/corrupt952/SnackTime) — Reminds you to take a break
- [Snack Cards](https://github.com/corrupt952/SnackCards) — Shows your Reading List as cards in a side panel

## MCP

- [nooon](https://github.com/corrupt952/nooon) — Lightweight Notion MCP Server

## GitHub Actions

- [actions-retry-command](https://github.com/corrupt952/actions-retry-command) — Retries a shell command on failure and captures its stdout and stderr as outputs

## Configuration

- [dotfiles](https://github.com/corrupt952/dotfiles) — Personal macOS workstation configuration managed with Nix flakes, nix-darwin, and home-manager
- [renovate-config](https://github.com/corrupt952/renovate-config) — Account-wide Renovate inheritance config and shared preset
